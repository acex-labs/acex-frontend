kind: added
title: Forms say when a serial number, hostname or node already exists
---
Creating or editing an asset, logical node or node now tells you when the serial number, hostname or logical node is already taken. The message appears under the field it is about, with a link to open the existing record. Saving an asset with a blank serial number is no longer possible. Claiming assets from the Unclaimed Assets page also shows the reason the server gave when a claim fails, instead of a bare "API error 409".
