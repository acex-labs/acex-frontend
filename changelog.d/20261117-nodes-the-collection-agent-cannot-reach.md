kind: added
title: Nodes the collection agent cannot reach are marked
---
A node the collection agent could not collect on its last try gets a red label next to its name, with the reason: unreachable, login failed, privilege level, SSH algorithm, no driver, no IP address, no credentials or empty config. Hover the label to see since when, how many attempts in a row and the message from the agent. The Overview tab has a Collection card beside Node Instance with the status (green when the node was collected, red with the reason when it was not), since when the node has not been collected, the attempts in a row, the reason, the last attempt, the collection agent that made it, and when its configuration was last synced and last changed (these two moved there from Node Instance). The agent's name is a link to its page under Settings > Collection Agents, which now opens on an agent from its address and has a Collection section: how many of the nodes the agent made the last attempt on were collected, how many were not and for which reasons, and a list of the nodes that were not, each linked to its page. The Nodes tab of a site shows the collection agent of each node, as a link to the same page. The Nodes list has a Collection filter to find the nodes that are not collected.
