title: The columns of the Nodes list can be chosen
---
The Nodes list has a Configure Table button. Pick the columns to show from a list of available ones, remove the ones you do not need and move them up or down, then Apply. Reset goes back to the columns the list had before. The choice is kept in this browser. New columns are available for the collection of a node: its status, since when it has not been collected and the collection agent that made the last attempt. The Collection filter is offered together with the Collection column, so a list that does not show collection has no filter for it either.
