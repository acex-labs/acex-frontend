title: Standard Actions and workflow steps run every action the API lists
---
Operations › Standard Actions and a workflow's action step list every action
the API offers: ping, the MAC address table, MAC lookup, IP route, the ARP
table, ARP lookup, traceroute and interface status. Each one's form is made
from its parameters as the API describes them, so a new action appears here
without a frontend change. A run's drawer shows a table action as a table,
says when the table was cut at Max entries, and shows a lookup as found or
not found and a traceroute as reached or not.
